# 📚 API RESTful de Biblioteca Digital (apiBookUTN)

Este proyecto es una API RESTful desarrollada como parte de un Trabajo Práctico. Permite gestionar una colección de libros utilizando el patrón de diseño MVC.

> ✅ **Estado del proyecto:** Completado.

## 🛠️ Tecnologías Utilizadas
*   **Node.js** con **JavaScript**
*   **Express** (Framework web)
*   **MongoDB** (Base de datos NoSQL)
*   **Mongoose** (ODM)
*   **Zod** (Validacion de esquemas)
*   **Git** (Control de versiones)

## ⚙️ Requisitos Previos
Antes de ejecutar este proyecto, asegúrate de tener instalado:
*   [Node.js](https://nodejs.org/) (v18 o superior)
*   [MongoDB Community Server](https://www.mongodb.com/try/download/community) (o tener una cuenta en MongoDB Atlas)
*   [MongoDB Compass](https://www.mongodb.com/products/compass) (opcional, para ver la base de datos)
